# Borcelle Hotel

A modern hotel landing page built with React and Vite.

## Features

* Responsive hotel landing page
* Hero section
* About section
* Rooms section
* Breakfast section
* Pool & leisure section
* Contact information
* Smooth scrolling navigation
* Responsive design

## Technologies

* React
* Vite
* JavaScript
* CSS
* HTML

## Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

The project will then be available locally in your browser.
